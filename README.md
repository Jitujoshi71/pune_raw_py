# Pune Raw Open Data

Fresh raw-data collection pipeline for the Pune 3D/Open-World project.

## What this repository collects

- Pune OpenStreetMap PBF
- Pune DEM tiles
- Pune Municipal Corporation OpenCity datasets
- SHA256 checksums
- Collection manifest
